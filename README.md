# Winboard News

חדשות **הגיזרה** בלשונית **"גלה"** של לוח הווידג'טים ב-Windows 11, גם כשהפיד המקורי של MSN חסום בסינון.

## התקנה (למשתמש)

1. הורד את `WinboardNews-Setup.exe` מ-[הגרסה האחרונה](../../releases/latest).
2. לחץ עליו ואשר את חלון ההרשאות של Windows (UAC).
3. זהו. אין חלונות ואין סרגל התקדמות. בסוף המתקין מאפס את לוח הווידג'טים ויוצא.

פתח את הלוח (Win+W) ועבור ל"גלה".

- **הסרה:** *הגדרות > אפליקציות > Winboard News > הסר*. זה מחזיר הכול כמו שהיה.
- **חלון "Windows protected your PC" (SmartScreen):** הקובץ לא חתום דיגיטלית. לחץ "More info" ואז "Run anyway".
- **אם ההתקנה נכשלה** תופיע הודעה עם הסיבה, והפרטים נשמרים ב-`%LOCALAPPDATA%\Programs\WinboardNews\install.log`.
- **דרישות:** Windows 11 ומחשב שמריצים עליו את ההתקנה עם המשתמש שיעשה בו שימוש בלוח. פורט 443 המקומי צריך להיות פנוי.

## מה זה עושה

| | |
|---|---|
| **חדשות** | הודעות הגיזרה בעברית (RTL), מהחדשה לישנה, עם גלילה אחורה בלי הגבלה (עד 600 הודעות בטעינה אחת). |
| **תמונה** | פס של 50 פיקסלים מראש התמונה מסמן שיש תמונה. לחיצה פותחת אותה בצד שמאל, והחדשות נשארות מימין. |
| **וידאו ואודיו** | מסומנים ב-"▶ וידאו" או "♪ אודיו", ונפתחים עם נגן באותה חלונית. |
| **רענון** | אוטומטי כל דקה, או בלחצן "רענון". |
| **מזג אוויר** | לא נוגעים בו. |

## איך זה עובד

הלוח טוען את `https://windows.msn.com/...`, ו-NetFree מפנה את הדומיין הזה לחיפוש בגוגל, ולכן מופיעה השגיאה
"לא ניתן לטעון את הלוח שלך" (פירוט בבדיקות: [docs/RECON.md](docs/RECON.md)).
המתקין גורם לדומיין הזה להגיע לשרת קטן שרץ אצלך במחשב:

```
לוח הווידג'טים (WebView2)
   └─ https://windows.msn.com/...
        │  hosts: windows.msn.com -> 127.0.0.1
        ▼
   WinboardNews.exe  (127.0.0.1:443, רץ ברקע בלי חלון, עולה עם Windows)
        ├─ העמוד שלנו
        └─ /news.json -> hagizra.news/api/messages  (cache של 45 שניות)
```

שלושה שינויים במערכת, כולם הפיכים בהסרה:

1. **קובץ hosts:** שורה אחת, `127.0.0.1 windows.msn.com  # winboard-news-proxy`. גיבוי נשמר כ-`hosts.winboard.bak`.
2. **תעודה מקומית** לדומיין `windows.msn.com` בלבד, שמוכרת ב-`LocalMachine\Root`. היא לא תעודת CA ולא יכולה לחתום על אתר אחר.
   המפתח הפרטי נשמר רק בתיקיית ההתקנה של המשתמש.
3. **הפעלה אוטומטית** של השרת בהתחברות (`HKCU\...\Run`), עם הרשאות רגילות ולא כמנהל.

המתקין, בסדר הזה: מעתיק את השרת ל-`%LOCALAPPDATA%\Programs\WinboardNews`, יוצר ומאשר את התעודה, מעדכן hosts,
רושם הפעלה אוטומטית והסרה, מפעיל את השרת, בודק שהוא עונה, ומאפס את תהליך הלוח (`WidgetBoard.exe`) כדי שיטען את העמוד החדש.

השרת מאזין ל-127.0.0.1 בלבד. הוא פונה להגיזרה דרך הרשת המסוננת כמו כל תוכנה אחרת, ולכן הסינון נשאר בתוקף.
רק קישורי https של `stream.hagizra.news` ו-`hagizra.news` נטענים כמדיה, והעמוד מוגן במדיניות CSP.

## פיתוח

דרישות: .NET 10 SDK. לבניית ה-EXE (Native AOT) גם Visual Studio עם רכיב C++.

```
dotnet test tests/WinboardNews.Tests
dotnet run --project src/WinboardNews -- --dev --port 8444     # http://127.0.0.1:8444/app.html, בלי hosts ובלי תעודה
```

| נתיב | תפקיד |
|---|---|
| `src/WinboardNews.Core` | ליבה: משיכת הגיזרה ונרמול, cache, שרת HTTP/TLS מינימלי, hosts, תעודה, והעמוד `app.html` |
| `src/WinboardNews` | `WinboardNews.exe`: השרת ברקע (WinExe, בלי קונסול) |
| `src/WinboardNews.Setup` | `WinboardNews-Setup.exe`: המתקין השקט (מבקש הרשאות מנהל), כולל את השרת בתוכו |
| `tests/` | בדיקות xUnit, כולל שרת HTTPS אמיתי |
| `.github/workflows/release.yml` | בכל commit ל-`main`: בדיקות, בנייה, ופרסום Release עם קובץ ההתקנה |

פרטים שחשוב לדעת:
- ה-API של הגיזרה: `offset` הוא מצביע "ההודעות שלפני מזהה X" (ולא היסט), ולכן גלילה אחורה משתמשת במזהה הקטן ביותר בעמוד הקודם.
- העמוד מקבל גרסה מהשרת וטוען את עצמו מחדש כשהיא משתנה, כי הלוח שומר עמוד ישן בזיכרון.
- לוח הווידג'טים שומר חיבורים ו-DNS ישנים, ולכן ההתקנה מאפסת אותו.
