# winboard-news-proxy

תחליף מקומי ללשונית **"גלה"** בלוח הווידג'טים של Windows 11, שמציג את חדשות **הגיזרה** במקום פיד MSN החסום.

## הבעיה
לוח הווידג'טים טוען את `https://windows.msn.com/app.html`. NetFree מפנה את הדומיין הזה לחיפוש בגוגל, ולכן מופיעה השגיאה
"לא ניתן לטעון את הלוח שלך". (הרחבה בממצאי הבדיקה: [docs/RECON.md](docs/RECON.md))

## הרעיון
```
Widgets board (WebView2)
   └─ https://windows.msn.com/app.html
        │  hosts: windows.msn.com -> 127.0.0.1
        ▼
   server.js (127.0.0.1:443, תעודה מקומית)
        ├─ /app.html   -> public/app.html  (העמוד שלנו)
        └─ /news.json  -> hagizra.news/api/messages (דרך NetFree, cache של 45 שניות)
```
- מזג האוויר בשורת המשימות ובאפליקציית מזג האוויר **לא נוגעים בו**: הוא משתמש בדומיינים אחרים.
- החדשות נמשכות מה-API של הגיזרה, באותה לוגיקה כמו `hagizra-widget` (ראה `src/news.js`).
- השרת פונה לשם דרך הרשת המסוננת כמו כל תוכנה אחרת, ולכן הסינון נשאר בתוקף.

## שימוש (ניסוי ראשון)
1. `npm test`: בדיקות יחידה (אופציונלי).
2. **התקנה (דורשת מנהל):** לחיצה כפולה על `install.cmd` ואישור UAC. הסקריפט:
   - מוסיף שורה ל-hosts: `127.0.0.1 windows.msn.com  # winboard-news-proxy` (גיבוי: `hosts.winboard.bak`).
   - יוצר תעודה עצמית **רק** לדומיין `windows.msn.com` (לא CA, לא יכולה לחתום על דבר אחר) ומוסיף אותה ל-`LocalMachine\Root`. המפתח הפרטי נשמר רק ב-`certs/server.pfx` (ב-`.gitignore`).
3. הרץ `start-server.cmd` והשאר את החלון פתוח (לא דורש מנהל).
4. פתח את לוח הווידג'טים (Win+W), עבור ל"גלה" ולחץ "רענון".
5. אם לא עובד: `scripts\status.ps1` מציג מה במקום, ו-`logs\requests.log` מראה מה הלוח ביקש.

**ביטול מלא:** `uninstall.cmd` (מנהל). מסיר את שורת ה-hosts, את התעודה ואת קובצי המפתח.

## בדיקה מקומית בלי לגעת במערכת
```
node server.js --http      # http://127.0.0.1:8443/app.html
```

## מה עדיין לא ידוע (מטרת הניסוי)
- האם הלוח מקבל עמוד שלא מדבר איתו בפרוטוקול של מיקרוסופט. `public/app.html` שולח ל-`/diag` נתוני אבחון (בין היתר האם `window.chrome.webview` קיים) שנרשמים ב-`logs/requests.log`.
- אילו בקשות נוספות הלוח שולח לדומיין הזה (נרשמות בלוג).
- האם עדכון של Windows משנה את הכתובת.

## מבנה
| נתיב | תפקיד |
|---|---|
| `server.js` | שרת HTTPS מקומי, בלי תלויות, מאזין ל-127.0.0.1 בלבד |
| `src/news.js` | משיכת הגיזרה, נרמול טקסט, cache עם backoff |
| `public/app.html` | עמוד החדשות (RTL, בהיר/כהה, בלי מדיה) |
| `scripts/install.ps1`, `uninstall.ps1` | שינויי מערכת הפיכים (מנהל) |
| `scripts/status.ps1` | בדיקת מצב (קריאה בלבד) |
| `test/` | בדיקות (`node --test`) |

דרישות: Node 20 ומעלה. אין תלויות npm.

## תמונות, סרטונים ואודיו
- בהודעה עם תמונה מופיע פס דק (10 שורות הפיקסלים העליונות של התמונה) וסימון "תמונה". הודעה עם וידאו או אודיו מסומנת ב-"▶ וידאו" או "♪ אודיו".
- לחיצה על ההודעה פותחת חלונית **בצד שמאל** עם כל המדיה שלה (תמונה, נגן וידאו, נגן אודיו), והחדשות נשארות מימין. לחיצה שוב, "סגור" או Esc סוגרים. סגירה עוצרת ניגון.
- המדיה נטענת ישירות מ-`stream.hagizra.news` (תומך בטעינה חלקית, ולכן אפשר לדלג בסרטון). רק קישורי https של הגיזרה נטענים; כל מקור אחר מסומן בטקסט בלבד.
- אחרי עדכון קוד צריך להפעיל מחדש את `start-server.cmd` (לסגור את החלון ולהריץ שוב).
